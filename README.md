# PROFILE.ZIP

> 취향을 모아 나만의 페이지로

레트로 홈페이지의 여러 창과 인스타식 콜라주 구성을 조합해 나만의 프로필 페이지를 만드는 이미지 편집기입니다. 사진과 글을 채우고 창을 배치한 뒤, 완성된 화면을 고해상도 PNG로 저장할 수 있습니다.

**[PROFILE.ZIP 바로 사용하기](https://mt0gn.github.io/profile-zip/)**

## 주요 기능

- 1:1, 4:3, 3:4 캔버스와 비율별 추천 배치
- 비율을 바꿔도 내용은 유지하고 위치와 크기는 비율별로 저장
- 프로필 아이디 카드, 사진첩, 태그, 메신저, 장식 배열, 음악의 기본 콘텐츠 6종
- 소개 메모와 영상 통화 등 필요할 때 추가하는 선택형 콘텐츠
- 디자인형·가로형·세로형 프로필 아이디 카드
- 슬롯별 사진 선택·교체·삭제와 사진 표시 위치 조정
- LIKES·HATES처럼 여러 구역을 나누는 태그 창
- 대화 수를 조정할 수 있는 메신저와 상대·내 사진을 꾸미는 영상 통화
- 비율별 이미지가 준비된 기본 배경 20종과 사용자 배경 업로드
- 배경별 테마 색상과 창 바탕·제목 표시줄·테두리·포인트 색상 조정
- 12종 픽셀 장식, 장식 배열, 확인 창·경고·커서 시스템 소품
- 콘텐츠 이동·크기 조절·복제·앞으로 보내기와 창 모양 변경
- 여러 페이지 생성, 복제, 삭제와 페이지명 변경
- 어두운 배경과 흰 배경에서 확인하는 전체 화면 미리보기
- 프로젝트 JSON 저장·불러오기와 고해상도 PNG 내보내기

음악 플레이어, 메신저, 영상 통화와 시스템 소품은 완성 이미지 안의 시각 요소입니다. 실제 음악 재생, 메시지 전송, 통화 기능은 제공하지 않습니다.

## 사용 방법

1. [배포된 편집기](https://mt0gn.github.io/profile-zip/)를 엽니다.
2. 1:1, 4:3, 3:4 중 작업할 비율을 선택합니다.
3. 기본 배경 20종 또는 사용자 배경을 고릅니다.
4. 캔버스의 콘텐츠를 선택하고 왼쪽 편집 창에서 사진과 글을 입력합니다.
5. 콘텐츠를 직접 옮기거나 `추천 배치로 정리`를 사용합니다.
6. 필요한 콘텐츠나 장식 요소를 추가하고 크기와 순서를 조정합니다.
7. `미리보기`에서 어두운 배경과 흰 배경으로 결과를 확인합니다.
8. `프로젝트 저장`으로 편집 원본을 보관하고 `PNG 저장`으로 이미지를 내보냅니다.

## 저장과 출력

편집 중인 데이터는 서버로 전송되지 않고 현재 브라우저의 IndexedDB 또는 localStorage에 저장됩니다. 브라우저 데이터가 삭제되거나 다른 기기·브라우저를 사용하면 자동 저장본이 이어지지 않으므로, 중요한 작업은 `프로젝트 저장`으로 JSON 파일을 함께 보관하는 것을 권장합니다.

PNG 출력 크기는 다음과 같습니다.

| 비율 | 출력 크기 |
|---|---:|
| 1:1 | 2000 × 2000 |
| 4:3 | 2400 × 1800 |
| 3:4 | 1800 × 2400 |

## 로컬 개발

일반 사용자는 로컬 서버를 실행할 필요가 없습니다. 소스를 수정하거나 배포 전 빌드를 확인할 때만 아래 명령을 사용합니다.

```powershell
npm run build
npm run preview
```

`npm run build`는 정적 배포본을 `dist`에 만들고 배경·레이아웃·기본 콘텐츠 구성을 검증합니다. `npm run preview`는 로컬 미리보기 서버를 실행합니다.

## 배포

`main` 브랜치에 변경 사항을 푸시하면 [GitHub Actions](.github/workflows/deploy-pages.yml)가 `dist`를 빌드한 뒤 GitHub Pages에 자동으로 배포합니다.

## 코드 구조

- `index.html`: 편집기 화면 구조와 브랜드 정보
- `styles.css`: 편집기 UI와 출력 콘텐츠 스타일
- `app.js`: 편집 화면 조립과 사용자 동작
- `src/config.js`: 비율, 배경, 팔레트, 추천 배치 설정
- `src/persistence.js`: 브라우저 자동 저장과 프로젝트 데이터 처리
- `src/output.js`: 전체 화면 미리보기와 PNG 렌더링
- `src/utils.js`: 파일·문자열·공통 유틸리티
- `pixel-icons.js`: 32×32 픽셀 장식 원본
