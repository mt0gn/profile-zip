# PROFILE.ZIP

여러 레트로 창을 옮겨 홈페이지 메인 화면처럼 꾸미는 편집기입니다. 완성된 기본 화면에서 사진과 글을 채우고, 창을 재배치해 한 장의 이미지로 저장합니다.

## 실행

브라우저 보안 정책 때문에 파일을 직접 열지 말고 로컬 웹 서버에서 실행하세요.

```powershell
python -m http.server 4317
```

그다음 `http://127.0.0.1:4317/`을 엽니다.

## 주요 기능

- 별도 시작 과정 없이 완성된 홈페이지형 메인 카드에서 바로 편집
- 프로필, 사진첩, 소개 메모, 음악, 태그, 메신저, 영상 통화 기본 창 7개와 선택형 최근 글 창
- 4:3, 1:1, 3:4에서 사진과 글은 공유하고 창 위치·크기는 비율별 독립 저장
- 4:3 가로 콜라주·1:1 중심 콜라주·3:4 세로 레일형으로 완성된 기본 배치
- 모든 기본 콘텐츠의 실제 표시 공간을 확보하는 `추천 배치로 정리` 기능
- 4:3, 1:1, 3:4 캔버스
- 색상환 순서로 정리된 기본 테마 20종(각 4:3·1:1·3:4), 단색 배경, 사용자 이미지 업로드
- 배경 맞춤, 흐림, 밝기, 색상 오버레이
- 디자인형·가로형·세로형을 선택할 수 있는 고정 비율 아이디 카드
- 한 장의 큰 사진부터 1~6칸 가로·세로·격자 배치까지 지원하는 사진첩
- 대화 말풍선과 상대 프로필을 편집하는 메신저 창
- 메인 화면·내 화면·통화 상태를 꾸미는 영상 통화 창
- LIKE·HATE·DREAM처럼 최대 4개의 소제목과 큰 단어 칩을 구성하는 태그 창
- 메모장과 정적 음악 플레이어
- 클린 카드, 슬림 바, Y2K 바, 클래식 PC, 아웃라인, 프레임리스 창 외형
- 페이지 기본 창 외형과 앱별 외형 덮어쓰기
- 사용자가 수정한 32×32 도트 원본을 그대로 반영한 폴더·문서·이미지·비디오·카메라·알림·채팅·음악·그림판·인터넷·메모리·쓰레기통 12종
- 창 바탕·제목색·테두리·포인트·그림자 역할을 분리해 배경 테마 색을 자동 상속하는 픽셀 아이콘
- 확인창·경고·커서는 독에 들어가지 않는 별도 시스템 소품으로 분리
- 픽셀 장식 또는 사용자 이미지 2~6개를 세로·가로로 균등 배치하는 장식 배열
- 장식 배열의 창 배경·투명 배경·하단 독 받침 전환
- 상단 문구·메뉴·하단 문구로 구성된 페이지 프레임
- GUI 요소의 테마 색 자동 상속과 바탕·강조·테두리·보조·글자색 개별 설정
- 앱과 요소의 이동, 크기 조절, 복제, 앞으로 보내기
- 여러 페이지와 완성형 창 색상 키트
- 큰 업로드 이미지도 보존하는 IndexedDB 우선 자동 임시 저장과 실패 안내
- 어두운 배경·흰 배경에서 최종 PNG와 같은 결과를 확인하는 전체 화면 미리보기
- JSON 저장·불러오기와 비율별 2배 고정 해상도 PNG 내보내기

음악 플레이어, 메신저, 영상 통화와 파일 모양은 완성 이미지 안의 시각 요소이며 실제 재생·통화·메시지 전송 기능은 없습니다.

## 배경 파일 규칙

배경은 `assets/backgrounds`에 테마별 세 파일을 둡니다.

```text
theme-name-4x3.png
theme-name-1x1.png
theme-name-3x4.png
```

새 테마는 `src/config.js`의 `BACKGROUND_THEMES` 목록에 이름, 세 이미지 경로, 추천 팔레트를 추가하면 됩니다.

## 권장 작업 순서

1. 상단에서 4:3, 1:1, 3:4 중 편집할 비율을 선택합니다.
2. 20종 배경 중 하나를 고릅니다. 비율별 배경 이미지와 어울리는 창 색상이 자동 적용됩니다.
3. 캔버스의 창을 선택해 사진과 글을 입력합니다.
4. 창을 드래그하고 크기를 조절해 메인 화면을 완성합니다.
5. 필요한 콘텐츠 창이나 장식 요소를 추가합니다.
6. 다른 비율로 이동해 해당 화면의 위치만 별도로 다듬습니다.
7. 배치가 흐트러지면 `추천 배치로 정리`로 현재 비율만 복구합니다.
8. `미리보기`에서 어두운 배경과 흰 배경으로 결과를 교차 검수합니다.
9. JSON 원본을 저장한 뒤 PNG를 내보냅니다. 출력 크기는 4:3 2400×1800, 1:1 2000×2000, 3:4 1800×2400으로 고정됩니다.

## 코드 구조

- `app.js`: 편집 화면 조립과 사용자 동작
- `src/config.js`: 비율, 배경, 팔레트, 추천 배치 설정
- `src/persistence.js`: IndexedDB 자동 저장과 이전 localStorage 데이터 이전
- `src/output.js`: 미리보기와 2배 PNG 렌더링
- `src/utils.js`: 파일·문자열·공통 유틸리티
- `pixel-icons.js`: 32×32 픽셀 장식 원본

## 빌드

의존성 없이 정적 배포본을 만들고 배경·레이아웃 구성을 함께 검증합니다.

```powershell
npm run build
```

완성된 파일은 `dist`에 생성됩니다.
